# Keenan Gunawan — Actuarial & Risk Analytics Portfolio

A documentation-style portfolio of actuarial, risk and data analytics case studies.

## Structure

- `index.html` — portfolio homepage
- `projects/` — individual project walkthroughs
- `code/` — cleaned source files linked from the walkthroughs
- `assets/` — shared styling and interaction code

The current case studies cover election polling in R, reverse-mortgage simulation in Excel/VBA, motor-insurance bonus-malus design in R, statistical and machine-learning workflows for Airbnb, an audited mortality-risk analysis, mortgage protection insurance pricing, and a market-risk study using copulas, VaR, Expected Shortfall and ARMA models. Original assignment briefs, raw submission files and student identifiers are intentionally excluded from the public portfolio.

## Local preview

Open `index.html` directly or serve the folder with a static web server.

## Publishing

This site is designed for GitHub Pages and can be published from the repository root once the repository is created.

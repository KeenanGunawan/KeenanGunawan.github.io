02

Fit preprocessing on training data

make_recipe <- function(training_predictors) {
  recipe(~ ., data = training_predictors) |>
    step_unknown(all_nominal_predictors(), new_level = "Missing") |>
    step_novel(all_nominal_predictors(), new_level = "New") |>
    step_other(all_nominal_predictors(), threshold = 0.01, other = "Rare") |>
    step_impute_median(all_numeric_predictors()) |>
    step_dummy(all_nominal_predictors(), one_hot = TRUE) |>
    step_zv(all_predictors()) |>
    prep(training = training_predictors, retain = TRUE)
}

The same trained recipe is then applied to validation and test rows. This prevents their category frequencies or medians from influencing model development.

Tune the classifier and threshold separately

class_xgb <- xgb.train(
  params = list(
    objective = "binary:logistic", eval_metric = "auc",
    max_depth = 3, eta = 0.05,
    subsample = 0.85, colsample_bytree = 0.85
  ),
  data = dclass_train,
  nrounds = 1200,
  watchlist = list(validation = dclass_validation),
  early_stopping_rounds = 60,
  verbose = 0
)

validation_roc <- roc(
  y_class_validation, validation_probability,
  levels = c("No", "Yes"), direction = "<"
)
threshold <- coords(
  validation_roc, "best",
  best.method = "youden", ret = "threshold"
)
Why it matters

AUC selects the ranking model without assuming a cutoff. The cutoff is a second decision, chosen only after the model is fixed and before the test probabilities are evaluated.

04

Correct log-price predictions

xgb_model <- xgb.train(
  params = list(
    objective = "reg:squarederror", eval_metric = "rmse",
    max_depth = 3, eta = 0.04,
    subsample = 0.85, colsample_bytree = 0.85
  ),
  data = dreg_train,
  nrounds = 1600,
  watchlist = list(validation = dreg_validation),
  early_stopping_rounds = 60,
  verbose = 0
)

train_log_prediction <- predict(xgb_model, dreg_train)
smearing <- mean(exp(log_y_train - train_log_prediction))

test_prediction <- pmax(
  0,
  exp(predict(xgb_model, dreg_test)) * smearing - 1
)

The smearing factor is estimated from training residuals. It corrects the downward bias that appears when a log prediction is simply exponentiated.

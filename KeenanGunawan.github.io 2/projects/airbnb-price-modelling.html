Melbourne Airbnb Price Modelling

A corrected comparison of linear regression and a Gamma GLM for advertised nightly prices, using consistent data, reproducible feature engineering and out-of-sample validation.

Source data10,052 listings
Model sample10,013 listings
ToolsR · GLM · Holdout testing
View cleaned R analysis

01

The decision question

Which listing characteristics are associated with Melbourne Airbnb prices, and which statistical model gives a more reliable nightly-price benchmark: ordinary linear regression or a model designed for positive, right-skewed outcomes?

Decision scope

The model estimates advertised nightly price. It does not estimate occupancy, revenue, expenses or investment return, so the final recommendation keeps pricing insight separate from a property-purchase decision.

03

Rebuilt modelling approach

  1. 1
    Use one modelling population

    Applied the same validation rules and 10,013-row dataset to both candidate models.

  2. 2
    Create interpretable features

    Counted listed amenities and log-transformed minimum nights and review counts to reduce extreme leverage.

  3. 3
    Hold out unseen listings

    Used a reproducible 80/20 split: 8,010 training listings and 2,003 test listings.

  4. 4
    Keep the comparison fair

    Fitted both models to the same raw price response and the same predictor formula.

  5. 5
    Test practical prediction quality

    Compared MAE, RMSE, RMSLE and invalid negative predictions against a median-price baseline.

05

What I corrected

I reviewed the earlier submission as a model-validation exercise. The revised version keeps useful exploratory work while correcting implementation and comparison problems that could materially change the conclusion.

Broken object flow

The original code referred to data_clean before creating it and later expected latitude and longitude after removing those columns. The new script creates each object once in a clear sequence.

Inconsistent responses

The original linear model used price while the Gamma model used log(price). Their AIC and BIC values were therefore not directly comparable. Both revised models use price.

Incorrect Gamma setup

A Gamma GLM with a log link already models a positive response multiplicatively. Applying it to log(price) distorted the model and produced misleading fit statistics.

In-sample validation

The original recommendation relied heavily on fitted diagnostics. The revised decision is based primarily on predictions for 2,003 listings excluded from training.

Lesson

A lower model-selection statistic is meaningful only when models use a comparable response and sample. Reproducibility checks should come before interpreting a dramatic improvement.

06

What the analysis says

Strong signals
  • Entire homes commanded much higher median prices than private or shared rooms.
  • Capacity, bedrooms and bathrooms were positively associated with price.
  • The negative squared-capacity term suggested diminishing returns from accommodating additional guests.
  • Neighbourhood remained important after controlling for listing characteristics.
Necessary caution
  • Advertised price is not realised revenue or profit.
  • Availability can mean either bookings or host-blocked dates.
  • Reviews and availability are post-listing outcomes, not pure property attributes.
  • Associations should not be interpreted as causal returns from renovations or amenities.

07

Recommendation and next iteration

Use the Gamma GLM as a pricing benchmark because it improved holdout accuracy, respected price positivity and better matched the response distribution. Do not use the model alone to choose an investment property.

Recommended next step

Add occupancy, booking dates, seasonality, cleaning costs, platform fees and local regulatory constraints. Then validate a revenue or cash-flow model using time-based testing before making an investment recommendation.

60-second interview explanation

“I analysed more than 10,000 Melbourne Airbnb listings and compared linear regression with a Gamma GLM. When I revisited the project, I found that my original comparison used different response scales, so the large AIC improvement was not valid. I rebuilt the pipeline with one dataset, the same price response and a fixed train-test split. On 2,003 unseen listings, the Gamma model reduced mean absolute error from $121 for a simple baseline to $84 and avoided negative price predictions. The biggest lesson was that model validation and decision scope matter as much as model complexity: a price model is useful for benchmarking, but it is not an investment-return model.”

Cleaned analysis code

A readable reconstruction of the analysis used for the election polling case study, with validation checks and the dependence correction identified during review.

The original polling dataset is not published here. Anyone with an authorised copy can place it at data/USpollGA.xlsx and run the script locally.

01

Validate data and estimate support

library(readxl)
library(dplyr)
library(tidyr)

poll <- read_excel("data/USpollGA.xlsx")

required_columns <- c("Candidate", "Gender", "Race", "AgeGroup", "Income")
missing_columns <- setdiff(required_columns, names(poll))

if (length(missing_columns) > 0) {
  stop("Missing required columns: ", paste(missing_columns, collapse = ", "))
}

support <- poll |>
  count(Candidate, name = "votes") |>
  mutate(sample_size = sum(votes), estimate = votes / sample_size)

support_intervals <- support |>
  rowwise() |>
  mutate(
    interval = list(binom.test(votes, sample_size)$conf.int),
    lower_95 = interval[[1]],
    upper_95 = interval[[2]]
  ) |>
  ungroup() |>
  select(-interval)

02

Build demographic comparisons

demographic_distribution <- function(data, variable) {
  data |>
    count({{ variable }}, Candidate, name = "votes") |>
    group_by({{ variable }}) |>
    mutate(percentage = 100 * votes / sum(votes)) |>
    ungroup()
}

gender_distribution <- demographic_distribution(poll, Gender)
race_distribution <- demographic_distribution(poll, Race)
age_distribution <- demographic_distribution(poll, AgeGroup)
income_distribution <- demographic_distribution(poll, Income)

03

Test support differences by gender

test_candidate_by_gender <- function(data, candidate_name) {
  total_by_gender <- table(data$Gender)
  support_by_gender <- table(data$Gender[data$Candidate == candidate_name])
  genders <- intersect(names(total_by_gender), names(support_by_gender))

  result <- prop.test(
    x = support_by_gender[genders],
    n = total_by_gender[genders],
    alternative = "two.sided",
    correct = FALSE
  )

  tibble(
    candidate = candidate_name,
    statistic = unname(result$statistic),
    p_value = result$p.value
  )
}

04

Account for multinomial dependence

Candidate proportions come from the same sample, so they are negatively correlated. The cleaned version includes that covariance rather than treating the two proportions as independent.

p_trump <- support |> filter(Candidate == "Trump") |> pull(estimate)
p_harris <- support |> filter(Candidate == "Harris") |> pull(estimate)
difference <- abs(p_trump - p_harris)

variance_component <- p_trump + p_harris - difference^2
z_99_one_sided <- qnorm(0.99)

n_required <- ceiling(
  z_99_one_sided^2 * variance_component / difference^2
)
Important

This remains an illustrative normal-approximation calculation. It does not account for weighting, design effects, non-response bias or future changes in voter intention.

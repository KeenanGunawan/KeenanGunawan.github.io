Audited survival-analysis pipeline

Selected code from the cleaned workflow. The downloadable script validates the input, constructs transparent cohorts, fits the survival models and prints every analysis denominator.

The raw linked health file is intentionally not published. Run the script with an authorised local copy: Rscript code/mortality-risk-analysis.R "/path/to/IPUMSNHIS_Processed.csv".

01

Preserve missing cancer information

dt[, any_recorded_cancer := fcase(
  breast_cancer == 1L | prostate_cancer == 1L |
    colorectal_cancer == 1L, "Recorded cancer",
  breast_cancer == 0L & prostate_cancer == 0L &
    colorectal_cancer == 0L, "No recorded cancer",
  default = NA_character_
)]
Guardrail

A single “No” response does not fill two missing organ-specific fields. The survival cohort is created directly from a recorded positive breast-cancer response.

02

Use one lifestyle definition

breast <- dt[breast_cancer == 1L]

breast[, favourable_profile := factor(fcase(
  bmi_group == "Normal" & smoking == "Never", "Favourable",
  !is.na(bmi_group) & !is.na(smoking), "Other",
  default = NA_character_
), levels = c("Other", "Favourable"))]

The public analysis calls this a favourable profile rather than a universally “healthy” person. Sleep is excluded because it is not sufficiently observed in the focused cohort.

03

Fit the model and test its assumption

breast_cox <- coxph(
  Surv(follow_up_years, death) ~
    age_at_survey + bmi_group + smoking +
    education + MARSTLEG,
  data = breast_cox_data,
  x = TRUE
)

summary(breast_cox)
cox.zph(breast_cox)
Why it matters

The Schoenfeld-residual check found evidence that age may not have a constant effect over time in the small cancer model. That is disclosed rather than hidden behind one hazard ratio.

04

Separate the descriptive and adjusted samples

phi_observed <- dt[!is.na(phi)]
phi_km <- survfit(
  Surv(follow_up_years, death) ~ phi,
  data = phi_observed
)

phi_cox_data <- dt[
  !is.na(phi) & !is.na(bmi_group) &
  !is.na(smoking) & !is.na(education) &
  !is.na(income)
]

phi_cox <- coxph(
  Surv(follow_up_years, death) ~ phi + age_at_survey +
    SEX + education + income + bmi_group + smoking +
    strata(survey_year),
  data = phi_cox_data
)

The Kaplan–Meier curve uses 1,249,332 observed PHI records. The complete-case adjusted model uses 116,477. Reporting both makes the missing-data cost visible.

01

Closed-form cumulative hazard

def cumulative_hazard(age, duration):
    background = (
        math.exp(EPSILON)
        * (math.exp(KAPPA * duration) - 1) / KAPPA
    )
    ageing = (
        math.exp(ALPHA + BETA * age)
        * (math.exp((BETA + KAPPA) * duration) - 1)
        / (BETA + KAPPA)
    )
    return background + ageing

Monthly death probabilities come from hazard increments between consecutive month boundaries, so no numerical integration is required.

02

Competing monthly decrements

def dependent_decrements(independent_death):
    qd = independent_death * (
        1 - MONTHLY_LAPSE / 2 - MONTHLY_PREPAYMENT / 2
        + MONTHLY_LAPSE * MONTHLY_PREPAYMENT / 3
    )
    ql = MONTHLY_LAPSE * (
        1 - independent_death / 2 - MONTHLY_PREPAYMENT / 2
        + independent_death * MONTHLY_PREPAYMENT / 3
    )
    qp = MONTHLY_PREPAYMENT * (
        1 - independent_death / 2 - MONTHLY_LAPSE / 2
        + independent_death * MONTHLY_LAPSE / 3
    )
    return qd, ql, qp
State update

The in-force proportion for the following month equals the current proportion multiplied by 1 − qd − ql − qp.

03

Solve the premium analytically

premium = (
    benefit_pv + fixed_expense_pv
) / (
    premium_annuity * (1 - TARGET_MARGIN)
    - commission_factor
)

epv_premiums = premium * premium_annuity
npv_profit = (
    premium * premium_annuity
    - premium * commission_factor
    - fixed_expense_pv
    - benefit_pv
)
profit_margin = npv_profit / epv_premiums

The equation is closed form because premium income and commission are both linear in the monthly premium.

04

Freeze the price before stressing risk

fixed_premium = baseline["B"]["monthly_premium"]

for rate in (0.065, 0.075, 0.085, 0.095):

Cleaned modelling pipeline

A reproducible script with explicit data validation, consistent model responses and an honest holdout comparison.

The source listing data is not published. Place an authorised copy at data/AirbnbMelbourne.xlsx, or pass its path as the first command-line argument.

01

Validate and clean once

required_columns <- c(
  "price", "room_type", "neighbourhood", "accommodates",
  "bedrooms", "bathrooms", "minimum_nights",
  "availability_365", "number_of_reviews", "amenities"
)

missing_columns <- setdiff(required_columns, names(raw))
if (length(missing_columns) > 0) {
  stop("Missing required columns: ", paste(missing_columns, collapse = ", "))
}

model_data <- raw[complete.cases(raw[required_columns]), required_columns]
model_data <- model_data[
  model_data$price > 0 & model_data$accommodates > 0 &
    model_data$bedrooms >= 0 & model_data$bathrooms > 0,
]

02

Create the modelling features

model_data$amenity_count <- vapply(
  strsplit(model_data$amenities, ",", fixed = TRUE),
  length,
  integer(1)
)

model_data$log_minimum_nights <- log1p(model_data$minimum_nights)
model_data$log_reviews <- log1p(model_data$number_of_reviews)
model_data$room_type <- droplevels(factor(model_data$room_type))
model_data$neighbourhood <- droplevels(factor(model_data$neighbourhood))
Design choice

The transformed count variables reduce extreme leverage, while the raw price response remains identical for both candidate models.

03

Create a reproducible holdout sample

set.seed(3142)
train_index <- sample.int(nrow(model_data), floor(0.8 * nrow(model_data)))

train <- model_data[train_index,]
test <- model_data[-train_index,]

The fixed seed produces 8,010 training rows and 2,003 test rows every time the script runs on the supplied dataset.

04

Fit comparable models

model_formula <- price ~
  room_type + neighbourhood +
  accommodates + I(accommodates^2) + bedrooms + bathrooms +
  log_minimum_nights + availability_365 + log_reviews + amenity_count

linear_model <- lm(model_formula, data = train)

gamma_model <- glm(
  model_formula,
  family = Gamma(link = "log"),
  data = train
)
Audit change

The Gamma model now uses positive price directly. The log link handles multiplicative effects and guarantees positive fitted values without double-transforming the response.

05

Evaluate unseen listings

model_metrics <- function(actual, predicted) {
  data.frame(
    MAE = mean(abs(actual - predicted)),
    RMSE = sqrt(mean((actual - predicted)^2)),
    RMSLE = sqrt(mean((log1p(actual) - log1p(pmax(predicted, 0)))^2)),
    MedianAE = median(abs(actual - predicted)),
    Negative_predictions = sum(predicted < 0)
  )
}

metrics <- rbind(
  Baseline = model_metrics(predictions$actual, predictions$baseline),
  Linear = model_metrics(predictions$actual, predictions$linear),
  Gamma = model_metrics(predictions$actual, predictions$gamma)
)

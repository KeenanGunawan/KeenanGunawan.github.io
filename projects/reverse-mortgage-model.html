01

CIR interest-rate process

The nominal rate is updated using a discrete Cox–Ingersoll–Ross step. The square-root term makes volatility depend on the current rate, while the mean-reversion term pulls the process toward its long-run level.

r_next = r_current
  + kappa * (theta - r_current) * delta_t
  + sigma * SQRT(r_current) * random_shock

' Workbook form
= D22 + ($C$16 * ($C$14 - D22) * $C$13)
      + ($C$17 * SQRT(D22) * C23)
Control

The workbook applies a 2.5% to 7.5% nominal-rate collar before converting the rate to the selected repayment period. In a production model I would test both the mathematical effect and commercial justification of that cap.

02

Dynamic amortisation

Each period recalculates the payment from the current balance and simulated effective rate, then splits that payment into interest and principal.

payment   = -PMT(effective_rate, remaining_periods, balance)
interest  = balance * effective_rate
principal = payment - interest
balance   = MAX(0, balance - principal)

The frequency dropdown feeds the time-step and parameter lookup. A worksheet event shows only the number of rows relevant to the chosen frequency, keeping one underlying schedule usable from daily to annual repayment intervals.

Private Sub Worksheet_Change(ByVal Target As Range)
    If Intersect(Target, Range("C12")) Is Nothing Then Exit Sub

    Select Case Range("C12").Value
        Case "Daily":         ShowModelRows 10971
        Case "Weekly":        ShowModelRows 1581
        Case "Fortnightly":   ShowModelRows 801
        Case "Monthly":       ShowModelRows 381
        Case "Quarterly":     ShowModelRows 141
        Case "Semi-Annually": ShowModelRows 81
        Case "Annually":      ShowModelRows 51
    End Select
End Sub

Private Sub ShowModelRows(ByVal lastVisibleRow As Long)
    Rows("22:10972").Hidden = True
    Rows("22:" & lastVisibleRow).Hidden = False
End Sub

03

Stochastic property model

A variance process and a house-price process evolve together using correlated shocks. The second independent shock allows the model to retain the selected correlation while still introducing separate variance noise.

variance_next = variance
  + kappa_v * (theta_v - variance) * delta_t
  + rho * sigma_v * SQRT(variance) * shock_1
  + sigma_v * SQRT(1 - rho^2) * SQRT(variance) * shock_2

price_next = price
  + mu * price * delta_t
  + SQRT(variance_next) * price * shock_1

The reverse-mortgage balance then compounds at 3.95% per year on a fortnightly basis:

reverse_balance_next =
  reverse_balance * (1 + 3.95% / 26) + withdrawal

04

VBA simulation loop

The original macro recalculated a single stochastic path and copied it into the results store 1,000 times. I refactored it for this portfolio with explicit types, calculation control and guaranteed cleanup.

For simulationIndex = 1 To SIMULATION_COUNT
    sourceSheet.Calculate

    resultsSheet.Cells(1, simulationIndex).Value = simulationIndex
    resultsSheet.Range( _
        resultsSheet.Cells(FIRST_PATH_ROW, simulationIndex), _
        resultsSheet.Cells(LAST_PATH_ROW, simulationIndex) _
    ).Value = sourceSheet.Range( _
        "E" & FIRST_PATH_ROW & ":E" & LAST_PATH_ROW _
    ).Value
Next simulationIndex

Controls I would add next

Reconciliation tests

Confirm opening balance minus cumulative principal equals closing balance, and separately reconcile cash withdrawn to the interest-accrued reverse-mortgage balance.

Controlled randomness

Use a seeded random-number generator and store scenario IDs so every chart and decision output can be reproduced.

Input governance

Move every assumption into a dedicated input sheet with units, sources, ranges and validation rules.

Distribution reporting

Report percentiles and downside measures alongside means, particularly when long-horizon compounding creates a heavy right tail.
